# HireSight-app
"Clear Vision. Fair Hiring."  Get job based on skills not resume ---


This project is a modern **Signup Authentication System** built using **React** and **Firebase Authentication + Firestore**. It supports user role-based navigation for two types of users:

- 🎯 **Candidate**
- 🏢 **Company**

Once a user signs up, they are redirected to their respective dashboard based on their role.

---

## 🛠️ Features

- 🔐 Signup with email and password using Firebase Authentication
- 🔄 Role-based routing (`Candidate` → `/candashboard`, `Company` → `/comdashboard`)
- 🧠 Firestore integration to store user details
- 💅 Clean UI with inline styles
- 🚨 Basic error handling with user-friendly messages
